# HD2D实机图工作流 · 出图主提示词

从[场景图库](atlas/README.md)按地点和功能选择参考，打开单幅确认后填入以下模板。同机位多时段共用第一张空间底图，单独生成各时段环境。下方的人物字段按委托填写，零 NPC、仅主角、多人或无人空镜均可。分层时只把环境和待预留的位置发给环境生成器。

```text
请制作一张可用作武侠 RPG 美术基准的 HD-2D 模拟实机截图。
地点与天气：[地点、天气]。时段：[白天／黄昏／夜晚]。
构图参考：[实际附的文件，借用哪些空间关系]。光照或材质参考：[实际附的文件，采用哪些画面特征]。
画面里的事：[此刻的活动或环境状态，例如封山雪道、开市或收摊]。
可走路线：[人物从哪里来，可到达哪两处，台阶或门口在哪里]。
光线：[光源位置和颜色] → 穿过[树隙、门洞、窗棂或灯罩] → 照到[两三处具体表面]。
主角：[是否入镜；入镜时填写脚底位置、朝向与遮挡]。
可见 NPC：[按活动逐人或按人群列出角色、数量、动作、区域；没有则写“无”]。落脚区与通行距离应容得下所列阵容。
底图所含人物：[分层时填“空景，图中所有人物、手持物及旧人影一并移除，固定设施保留”；单张需要保留路人时，列出具体 NPC 与站位]。

按附图分工。按空间参考确定观察高度、可走路线和建筑尺度，按本次地貌确定地表纹理与主色。借用光照参考的景深过渡、局部体积光或高光柔边。参照异地画面时，仍采用本次指定的建筑、服饰和活动。若有同机位底图，保留其建筑、地形与裁切。

镜头固定正向，横向平视建筑正面，只有轻微俯视，偏航与横滚为零。用正常跑图距离，一屏容得下一段街面或一间屋子。主要屋脊、门楣、岸线或柜台平行于屏幕横边，主角可沿画面左右走动。通过台阶的踏面和立面、门洞的厚度、檐下暗面和互相遮挡体现三维结构。室内也保持同一视轴。避免斜转等距或低机位宣传片构图。

有人物入镜时，为名单中的角色预留站立、遮挡和手持物的空间；无人空镜直接完成环境。仅当本次底图需要画 NPC 时，附上人物画风原帧，以其眼睛、下颌、帽沿和衣袖的像素格大小作参照。

给出三个具体深度。靠镜头的[水面反光／栏杆]逐渐虚化，反光松散成小片。人物所在的[石岸／街面]留下可辨的石缝、门槛和手边道具。远处的[屋瓦／树冠]降低纹理对比，窗灯有柔边。屋瓦、石面、树叶按距离收细节，亮部保留层次。

让光照的覆盖范围在缩略图上也读得出来。白天用一片受树枝或门洞切分的阳光照过路面，有冷影、半影和局部反光。黄昏让斜阳覆盖一侧道路，灯笼和窗光在另一侧分别照亮墙面与门槛。夜晚用深蓝环境光托住暗部，暖灯照开数个人物身位；窗里的光越过窗台，落到墙脚、台阶或木地板。只选当前时段适用的描述。雾、尘、炉烟中可见局部丁达尔光束，光源、遮挡、受光面和投影方向一致。湿石和水面给出被材质打断的倒影，保留其余区域的底色。

同机位换光时锁住首张底图的裁切、视角、树木、摊位和台阶。按开头约定生成该底图，预留后续合成角色的位置和投影范围。输出单幅约 16:9 横屏，无拼图、标题、字幕或水印，默认关闭 HUD。
```

一组可直接代入的夜景参数：秋夜驿站，雨刚停；驿卒在檐下查验行囊，玩家沿石路走到马棚门口；门外风灯越过灯罩照亮石阶和一段系马桩，纸窗暖光穿过窗格落到湿砖上；宇文逸脚底在画面左起 46%、上起 69%，朝右。参考《雨后药摊》与夜晚渡口的路灯覆盖范围。

**渡口晴朗正午的替换段**。高处偏左的日光穿过柳叶空隙，贴近树冠的湿空气里能看到几束宽窄不齐的浅金白光，柳荫后的暗墙衬出光路。光落到中央台阶的踏面和石岸中段，柳影把亮斑切开。棚下和踏步立面留冷影，船边水面有短促的银亮反光。按当前地点替换遮挡物、介质、承光面和阴影。

## NPC 透明帧

```text
图一是宇文逸的像素原帧。用同一套跑图人物的像素尺寸，制作[职业、朝向、姿态、服饰与手持道具]的完整透明站姿。匹配原帧头肩比例、眼睛占格、下颌阶梯和袖口折线。脸颊用少量大色块，眼睛用少数深浅格，发带、衣领和手部用同样粗细的轮廓。年龄和职业通过眉形、发色、衣装与道具表现。中性环境光，各时段单独补光。帽顶、两只靴和道具末端完整，四周透明留边，无地面、投影和文字。多人同张时每人独立留白，脚底对齐，便于分别裁出。
```

## 已有场景只改路人

```text
图一是原尺寸场景中包含主角和[目标路人]的局部，图二是主角像素来图。只编辑图一里的[目标路人]。让他的脸部用色、眼睛大小、衣褶分块和阶梯轮廓与图二一致，像素颗粒按两人的景深调整。保留[路人的职业衣装、手势、拿着的道具]和原有遮挡。主角沿用图一已有像素，保留构图、地面与光源。输出同取景的场景局部供贴回原图。
```
