# 西幻 HD-2D 实机图

铃溪镇是本工作流的西幻视觉基准。用户认可桥头一组的画面效果，同时要求新图拥有自己的地图。染布巷记录了从独立布局恢复建筑材质、光照和景深的做法。所有西幻地点沿用这套成像方式，建筑文化、季节、人物与活动按委托设计。

## 实际附图

- 新地图的第一张附件选包内完整成图。[晨光桥头](../examples/铃溪镇/桥头.png)适合校准日间屋面与树隙光，[染布巷](../examples/铃溪镇/染布巷.png)示范原创建筑和逐面景深，[集市](../examples/铃溪镇/集市.png)适合看街面焦带，[夜间磨坊](../examples/铃溪镇/夜间磨坊.png)示范冷环境光与近窗暖光。选择最接近本次光源和视距的一张，实际附给生成器。
- 从[高清图库](hd/README.md)选匹配地点或时段的《八方旅人Ⅱ》完整原帧作为下一张，分别注明要借用的材质、受光范围、焦点或人物尺度。另画布局时，把草图放在完整画风参考之后。材质切片只补充具体问题；单靠切片会丢失整幅的明暗与焦点关系。
- 新场景先设计入口、可达的交互点、出口及建筑占地。对照原帧看主楼轮廓、路的转向、前景遮挡和高差；若桥、台阶、屋列仍逐一对得上，先改地图再取样。参考建筑的渲染处理可迁移到石造堡垒、砖窑、雪地驿舍或室内，不必处处盖茅屋。

## 从环境到成图

1. **先做无人环境。** 拟定主光穿过什么、照亮哪块屋面和可走地面、何处仍有环境冷光。屋脊、檐口和墙身要读出不同朝向。以[建筑取样](../examples/铃溪镇/建筑取样.png)看柔亮材质、深檐、暗梁和贴图颗粒的相对大小。木、石、雪、积水都有自己的亮边宽度。密而平均的砖线、逐片发亮的光滑屋瓦、统一橙色罩染都应回到环境底图调整。
2. **按物距处理景深。** 先指定人物脚下和交互物所在的焦带。近遮挡失焦仍保留大轮廓；门面和前檐清楚；后屋坡、庭墙、远树依次检查，实际距离相近的部件保留相近锐度。局部光晕只在足够亮的屋檐、窗火、水面反光附近出现。雾、尘、雪粒随光源与空气条件安排。生成结果的焦点仍有偏差时，为该地点的实际表面制作灰度蒙版，将原底图与柔化副本混合，再叠人物。染布巷的蒙版只适配其定稿机位。
3. **按同一逻辑像素格分层排人。** 先看[跑图人物取样](../examples/铃溪镇/跑图人物取样.png)，按委托设计新角色。需要相同队伍时可直接复用[旅人透明帧](../examples/铃溪镇/分层/旅人.png)。染布巷的角色本体为 35–36 个逻辑像素高，带透明余边；定稿里中景旅人约 104 像素高，画高 941 像素。新图按同一景深的门洞和地面重新量。用近邻放大、脚底接触影、朝光侧和背光侧分别着色；远处人物与身旁道具采用相应的柔化。空镜直接使用环境图。
4. **在新地点检验。** 先把代表图与第一张完整基准等宽缩到约 600–650 像素，看建筑、可走区、亮斑与前后层次。再以相近建筑屏占比对照屋面和檐下局部；按原尺寸核对人物轮廓、足底、边缘光。成批出图时每处都回到固定基准，首张成品可补充角色和城镇设定。记录哪张日光、雾光或远景仍有差距。色调或整体亮度相近仅是一个观察项。

## 新场景提示词骨架

```text
第一张附件是本工作流的完整西幻成图，以它校准整幅实机效果，包括建筑贴图尺度、檐下暗部、亮面散射、人物相对门高和中景焦带。第二张是[地点、时段]游戏原帧，观察[具体的光照、材质、景深关系]。
创作一处新的[地点]。玩家从[入口]经[地形与转折]到[可交互设施及出口]。主建筑是[原创体量、结构与材料]，近处[遮挡]、人物所在层[清晰表面]、远处[随物距柔化的对象]。光从[位置]经[遮挡或介质]照到[具体表面和地面]，旁侧[冷影及局部反光]。为[阵容]留出脚底和道具位置，先生成无人横屏环境，关闭界面。
```

已有原创底图要局部修订时，编辑目标放第一张，随附完整风格基准和确有需要的局部取样。若多次修订后材质重新偏向插画，把完整风格基准恢复到第一位，原创底图放第二位，只从它承接地图与建筑功能。对照[实际生成提示词与附件次序](../examples/铃溪镇/实际生成提示词.md)。

## 复现本轮示例

从技能根目录运行下列命令，重建[染布巷成图](../examples/铃溪镇/染布巷.png)。脚本使用包内定稿底图、按物距绘制的蒙版、三张透明人物帧以及固定站位和灯光参数。需要 Python 3、FFmpeg、ffprobe。输出选用新文件名。

```sh
sh examples/铃溪镇/复现染布巷.sh renders/铃溪镇-染布巷.png
```
