# HD2D实机图工作流 · 出图主提示词

题材留空即用下方武侠模板。只有明确指定西幻时才转到[西幻附件顺序与新场景模板](西幻实机图.md)。

新武侠场景从[四地定稿](武侠四地定稿/选图与光照.md)选一张完整单幅作第一张实际附件。特殊机位可选[六景](visuals/昼暮夜六景.jpg)中的对应单幅或[雨后药摊原图](visuals/雨后药摊原基准.png)。另从[高清取景索引](hd/README.md)打开本次地点的实景。局部修改或同机位换光时，待编辑底图排第一。单图暂缺时，可在[待补清单](hd/待补画面.md)核对现有尺寸。

二期先填[局部区域规格](局部区域与随镜用光.md)：区域名、横×纵屏数、制作方法、单屏尺寸、相邻出口和共用地标。按当前局部区域选参考。测试随镜用光时，再填写同一段路上三个站位及各自的受光和投影，三帧从共用底图取景。 白天拼成全幅后跑逐屏人景比例检查，随本次生成记录保存实际量点和试站对照。

从[场景图库](atlas/README.md)按地点和功能选择参考，打开单幅确认后填入以下模板。同机位多时段共用第一张空间底图，单独生成各时段环境。下方的人物字段按委托填写，零 NPC、仅主角、多人或无人空镜均可。分层时只把环境和待预留的位置发给环境生成器。

```text
请制作一张可用作武侠 RPG 美术基准的 HD-2D 模拟实机截图。
地点与天气：[地点、天气]。时段：[白天／黄昏／夜晚]。
画风与镜头：[成图基准文件；沿用其正向俯角、树形和行走带的对焦。填写两项可核对关系，例如屋面占宽、人物与门洞的高度、近景遮挡或远景位置]。
场景尺度：[本次单屏或局部区域的用途；玩家在一个实际游戏视口的可见身高、每屏容纳的店面或地形段数、同进深站姿与门楣或柜面的关系]。
人物与建筑的尺寸基准：[同景别定稿、一个视口的像素高度、发顶到靴底的可见像素高度]。门槛到[门楣或卷帘下沿]约等于[几个人高]；同层[凳面至地面、柜台或栏杆]约等于[几个人高]。在可走地面留下相应的试站空间，同一条街和各时段复用这组尺度。
地点参考：[实际附件名，只采用指定的地貌、建筑与路线]。光照参考：[实际附件名，采用具体光源、散射或材质边缘的哪种表现]。
画面里的事：[此刻的活动或环境状态，例如封山雪道、开市或收摊]。
可走路线：[从人物脚下沿屏幕左右或上下走到哪个地标，在哪里转向，能进哪扇门或到哪块实地]。街巷以横街、纵巷为主。林道和山径让短斜段、缓弯顺着岸线或岩肩自然接路。台阶的宽度、级数随路宽和真实高差确定。
整屏用光：[时段、主光方位和颜色、阴影里的天光或室内反光]。沿可走路线写明[遮光物、它投影的地段、相邻的受光面]。把同一光向落实到人物受光侧、鞋底接触影和邻近立柱的投影。写一处随深度变暗的空间，以及一处需要保留的材质亮边。
空气里的光路（按需填写）：[透光空隙和介质] → [可见的一小段光路] → [受光面，或截断光路的遮挡物]。若只有地面或窗边受光，写清亮斑位置和檐下暗面，保持空气通透。
主角：[是否入镜；有玩家时将可见身形的中点对准当前单屏视口中心，填写身高、两脚落点、朝向与遮挡。画底图时在这里留可站的实地]。
可见 NPC：[按活动逐人或按人群列出角色、数量、动作、区域；没有则写“无”]。落脚区与通行距离应容得下所列阵容。多人市集、宴席和巡游填写各自的透明人物帧、落脚点、握持或桌面遮挡关系。前后排成人按主角的逻辑像素格与同一显示倍率摆放，儿童按年龄画小，坐姿按动作降低身形。
底图所含人物：[分层时填“空景，图中所有人物、手持物及旧人影一并移除，固定设施保留”；单张需要保留路人时，列出具体 NPC 与站位]。

按附图分工。沿用成图基准的机位与人物尺度。按地点参考重设建筑、可走路线和地表纹理。借用光照参考的景深过渡、局部体积光或高光柔边。参照异地画面时，仍采用本次指定的建筑、服饰和活动。若有同机位底图，保留其建筑、地形与裁切。

镜头固定正向，横向平视建筑正面，只有轻微俯视，偏航与横滚为零。用正常跑图距离，一屏容得下一段街面或一间屋子。主要屋脊、门楣、岸线或柜台平行于屏幕横边，主角可沿画面左右走动。通过台阶的踏面和立面、门洞的厚度、檐下暗面和互相遮挡体现三维结构。室内也保持同一视轴。避免斜转等距或低机位宣传片构图。

有人物入镜时，为名单中的角色预留站立、遮挡和手持物的空间；无人空镜直接完成环境。仅当本次底图需要画 NPC 时，附上人物画风原帧，以其眼睛、下颌、帽沿和衣袖的像素格大小作参照。

门后、阶上或隔岸还看得见下一处可达地点。有玩家时，以中央玩家和身边可交互范围为最清楚的一层，越过这片范围的物件随实际距离平滑失焦。横向路面过渡自然，保留主角的像素边，按其可见发顶与附近物件安排头顶的清晰余量。按本景选一件会穿过清晰区边缘的物件，写清它的完整轮廓、与主角的前后关系，以及哪些空隙能看到后景。按本场景写明近、中、远各一件物体。靠镜头的[水面反光／栏杆]逐渐虚化，反光松散成小片。人物所在的[石岸／街面]留下可辨的石缝、门槛和手边道具。远处的[屋瓦／树冠]降低纹理对比，窗灯有柔边。屋瓦、石面、树叶按距离收细节，亮部保留层次。

按本时段填写。白天：[日光与地面投影]。城镇黄昏：[低位夕阳照到的立面、路面、长影，树隙或楼间薄尘中可见的少量光束及落点]；[已点亮的窗灯、檐灯或街灯与其局部光池]。城镇夜间：[逐栋房屋的灯火，桥头、转角和路段的路灯，每个光池照到的实物]；[灯池之间由何方月光、天光或邻面反射照出路形]。室内结合开口和实际灯具；野外按日月、天光和遮挡布光。地面反馈：[光源、干湿和粗糙度决定的漫反射、磨亮边或碎倒影，在哪里被截断]。除非明确指定深夜无光，保留各处可读的照明层次。

同机位换光时锁住首张底图的裁切、视角、树木、摊位和台阶。按开头约定生成该底图，预留后续合成角色的位置和投影范围。单屏输出约 16:9 横屏。区域整图直出时按横纵屏数确定整区比例；接画时输出本次带重叠的单屏区块，合并后交同范围的完整区域。关闭 HUD，成图无标题、字幕或水印。
```

一组可直接代入的夜景参数：秋夜驿站，雨刚停；驿卒在檐下查验行囊，玩家沿石路走到马棚门口；门外风灯越过灯罩照亮石阶和一段系马桩，纸窗暖光穿过窗格落到湿砖上；两盏灯之间由偏冷的月光照出路边石沿；宇文逸身形居中朝右。例如画幅为 1672×941、人物可见身高为 112 像素时，两靴中点约在 (836, 527)，此处预留一段平坦石路。参考《雨后药摊》与夜晚渡口的路灯覆盖范围。

**渡口晴朗正午的替换段**。高处偏左的日光穿过柳叶空隙，贴近树冠的湿空气里能看到几束宽窄不齐的浅金白光，柳荫后的暗墙衬出光路。光落到中央台阶的踏面和石岸中段，柳影把亮斑切开。棚下和踏步立面留冷影，船边水面有短促的银亮反光。按当前地点替换遮挡物、介质、承光面和阴影。

正常版完成人物合成后，从该正常版生成主角镜头景深参考。环境生成请求只负责正常版的构图与自然景深，额外的镜头景深由局部后处理产生。调白天市街时可实际附上[鼓楼正常版](../examples/鼓楼市街/白天·正常版.png)，观察摊棚内外、树影中的伙计和日照下的街面。交付前按[定稿焦带与验图方法](../examples/鼓楼市街/用光与焦带.md)对照同层细节与远近过渡。遇到跨越行走带的物体，按[物体焦带与验图](../SKILL.md#按物体划分焦带)核对轮廓、空隙和遮挡。

## NPC 透明帧

```text
图一是宇文逸的像素原帧。用同一套跑图人物的像素尺寸，制作[职业、朝向、姿态、服饰与手持道具]的完整透明站姿。匹配原帧头肩比例、眼睛占格、下颌阶梯和袖口折线。脸颊用少量大色块，眼睛用少数深浅格，发带、衣领和手部用同样粗细的轮廓。年龄和职业通过眉形、发色、衣装与道具表现。中性环境光，各时段单独补光。帽顶、两只靴和道具末端完整，四周透明留边，无地面、投影和文字。多人同张时每人独立留白，脚底对齐，便于分别裁出。
```

## 已有场景只改路人

```text
图一是原尺寸场景中包含主角和[目标路人]的局部，图二是主角像素来图。只编辑图一里的[目标路人]。让他的脸部用色、眼睛大小、衣褶分块和阶梯轮廓与图二一致，两人共用原帧的像素格和显示倍率，焦外软化在合成后随各自的实际位置处理。保留[路人的职业衣装、手势、拿着的道具]和原有遮挡。主角沿用图一已有像素，保留构图、地面与光源。输出同取景的场景局部供贴回原图。
```
